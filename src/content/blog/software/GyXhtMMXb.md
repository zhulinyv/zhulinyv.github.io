Folder Move 是一款免费的便携式小工具，实际上是Windows命令行软连接的一个GUI版本，可以在 Windows 系统中将文件夹内容移动到另一个目标，而不会丢失原始文件夹中文件的（NTFS）访问权限。当你希望将某个文件夹移动到另一个磁盘、分区或位置时，使用 Folder Move 可以方便地转移权限，这对多用户 PC 和文件服务器上的批量文件转移是非常简便和高效的。
