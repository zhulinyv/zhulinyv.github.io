# 追忆

似乎再也回不去了？变的是我嘛？为什么世界变了？  
儿时的温暖…慢慢淡去……

# 追忆

小学，还是那个内向的天真的学生。被欺负还会像女孩子一样躲起来哭泣，喜欢看书，备受宠爱。似乎你就是男主，天生丽质难自弃。  
匆匆六年，到了初中，你改变了狠多，变得外向开朗，喜欢鹤立鸡群的感觉。每次考试似乎都是年级顶尖水平，学习不怎么努力，却拿着别人羡慕的成绩。

# 认识

小学，不记得几年级了，那是你第一次被周围亲近的人欺骗。你第一次尝到了发自内心的愤怒与失落，对因为欺骗而失去的感到惋惜，咒骂自己的犹豫不决，咒骂欺骗你的人，咒骂你曾珍惜过的东西……  
初中，是青春期嘛？我很讨厌这个说法，为什么在社会只有儿童和成人之分，而没有青春期这一类？我认为的青春期，不过是自己真正地开始认识这个社会。那时，你似乎还对这个世界抱有希望，认为只要相信，就一定可以达到。但是，你错了。那是你第二次、第三次……地被亲近之人欺骗。深夜，你独自一人走在河边的路上，你曾嘲笑那些轻生之人，可笑，现在你却对他们充满同情和理解。寒风一道道划在脸庞，却吹不醒迷茫的你。那时，你体会到了，世界上只有一人你可以相信，那就是你自己。

# 沉思

化作一个茧，把自己包裹起来，你与他人保持距离，却又伪装起来与人交好。  
初中，你有了第一台属于自己的电脑，很卡，但你觉得已经发挥了其最大价值。你开始了解计算机，开始喜欢计算机，却没人了解你……你开始在网络上寻找存在，帮助他人解决问题，或者与他人闲聊，即使没有一句感谢，但你却感到满足。

# 转折

一晃到了高中，那是你第一次尝到了嫉妒的感觉，你开始努力，却收效甚微。网课，你了解到了更多在平时了解不到的东西，你看到了社会的另一面，看到了世界的深处。你厌恶了主动帮助他人，厌恶了从前那个没有实力却凡事都想帮助的你。你，又给自己裹上了更厚的伪装……

# 深渊

你开始了解万物的负面，你开始怀疑曾经坚信的东西。

# 深渊

你似乎明白了，所谓如今看到的蓬勃发展、蒸蒸日上不过是隐藏了另一面哄骗自己的话语罢了。

# 深渊

很痛苦，你开始冷眼看待万物。开始嘲讽那些主管意识极强的网络喷子，开始真正了解这个世界。

# 讽刺

可笑，这世间明明有那么多不公……手按在键盘，却敲不出来几个字。
